Steps to Run Hybrid RAG for Evidence-Grounded Knowledge Discovery & Learning

1. Open PowerShell.

2. Go to the project folder:

   cd "C:\Users\ASUS\Downloads\autonomous-rag-agent"

3. Create the virtual environment:

   python -m venv venv

4. Activate the virtual environment:

   .\venv\Scripts\Activate.ps1

5. Install the required packages:

   python -m pip install -r requirements.txt

6. Create the environment file:

   Copy-Item .env.example .env

7. Open the environment file:

   notepad .env

8. Replace the example API key with your Groq API key:

   GROQ_API_KEY=your_actual_groq_api_key

9. Save and close the file.

10. Optional: rebuild the PDF search index:

   python ingest.py

11. Start the FastAPI application:

   python -m uvicorn main:app --host 127.0.0.1 --port 8000

12. Open the web application:

   http://127.0.0.1:8000

13. To stop the application, press Ctrl+C in the PowerShell terminal.

The FastAPI backend serves the dark Tailwind-style frontend from static/index.html.
The frontend and backend run together on port 8000; no separate frontend server or
Node.js build is required. The browser calls REST endpoints exposed by main.py.
