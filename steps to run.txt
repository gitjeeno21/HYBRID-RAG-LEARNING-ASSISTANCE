AUTONOMOUS RAG AGENT - COMPLETE WINDOWS RUN GUIDE

PROJECT
-------
This project provides a Streamlit web application for chatting with PDF
documents. It uses local Chroma embeddings, a local BM25 index, and Groq for
answer generation.


REQUIREMENTS
------------
- Windows 10 or Windows 11
- Python 3.11 (the version used to develop and test this project)
- Internet access for package installation and the first embedding-model
  download
- A free Groq API key from: https://console.groq.com/keys
- At least 4 GB RAM is recommended
- At least 2 GB of free disk space for Python packages and the local model

Check Python before continuing:

   python --version

The result should be Python 3.11.x. If python is not available, install
Python 3.11 from https://www.python.org/downloads/, select "Add Python to
PATH" during installation, and reopen the terminal.


FIRST-TIME SETUP
----------------
1. Open PowerShell.

2. Change to the project folder:

   cd "C:\Users\ASUS\Downloads\autonomous-rag-agent"

3. Verify that these important files exist in the folder:

   app.py
   ingest.py
   requirements.txt
   data\
   .env.example

4. Create a virtual environment:

   python -m venv venv

5. Activate it in PowerShell:

   .\venv\Scripts\Activate.ps1

   If activation succeeds, (venv) appears at the beginning of the prompt.

   If PowerShell reports that scripts are disabled, allow activation for the
   current terminal by running:

   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   .\venv\Scripts\Activate.ps1

   Alternatively, activate in Command Prompt:

   cd "C:\Users\ASUS\Downloads\autonomous-rag-agent"
   venv\Scripts\activate.bat

6. Upgrade pip and install the dependencies:

   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt

   Always run these commands using the active virtual environment. If the
   terminal does not show (venv), install with the explicit virtual-environment
   interpreter instead:

   .\venv\Scripts\python.exe -m pip install --upgrade pip
   .\venv\Scripts\python.exe -m pip install -r requirements.txt


CONFIGURE THE GROQ API KEY
--------------------------
1. Sign in to https://console.groq.com/keys and create an API key.

2. In PowerShell, from the project folder, create the local environment file:

   Copy-Item .env.example .env

3. Open .env:

   notepad .env

4. Replace the example placeholder with the actual key, with no quotation
   marks or extra spaces:

   GROQ_API_KEY=your_actual_groq_api_key

5. Save and close the file.

Do not share the key, send it in screenshots, or commit .env to GitHub. The
.env file is local configuration and is ignored by Git in this project.


PREPARE THE KNOWLEDGE BASE
--------------------------
The default source documents are PDF files inside the data\ folder.

- To use existing PDFs: keep the PDF files in data\.
- To add PDFs: copy them into data\.
- To remove PDFs: use the app's Remove Papers option or move them out of data\.
- PDF filenames should be unique enough for clear source citations.

Before the first web-app run, it is recommended to build the vector index:

   .\venv\Scripts\python.exe ingest.py

This process:
- Reads every PDF in data\
- Creates text chunks from the PDF pages
- Downloads the all-MiniLM-L6-v2 embedding model if it is not cached
- Rebuilds chroma_db from the PDFs in data\
- Displays progress and the final number of indexed chunks

Do not interrupt ingestion unless necessary. Re-run ingestion after adding,
replacing, moving, or removing PDF files from data\. The ingester rebuilds
chroma_db, so it may be slow for a large collection but prevents stale chunks
from remaining in the index.

The vector index can also be built automatically by the web app on first use,
but running ingest.py beforehand gives clearer startup progress and avoids
waiting inside the browser.


RUN THE WEB APPLICATION
-----------------------
1. Open PowerShell and change to the project folder.

   cd "C:\Users\ASUS\Downloads\autonomous-rag-agent"

2. Activate the environment if (venv) is not already shown:

   .\venv\Scripts\Activate.ps1

3. Start Streamlit:

   python -m streamlit run app.py

   Equivalent commands:

   streamlit run app.py
   .\venv\Scripts\python.exe -m streamlit run .\app.py

4. Wait until Streamlit prints a Local URL. It is usually:

   http://localhost:8501

5. Open that URL in a browser. Streamlit can also open the application
   automatically. Keep the PowerShell terminal open while using the app.

6. Ask a question based on one of the PDFs, or use the sidebar tools:

   - Upload new PDFs
   - Remove selected PDFs
   - Compare two PDFs
   - Generate a quiz
   - View retrieved source citations

7. To stop the app, return to its terminal and press Ctrl+C.


AFTER SETUP: NORMAL STARTUP
---------------------------
For later sessions, use:

   cd "C:\Users\ASUS\Downloads\autonomous-rag-agent"
   .\venv\Scripts\Activate.ps1
   python -m streamlit run app.py

No dependency installation or API-key setup is needed unless the project
environment or .env file was changed.


MANAGE PDFs
-----------
Add PDFs with either of these methods:

1. Upload through the Streamlit sidebar.
2. Copy PDF files into data\ and run:

   .\venv\Scripts\python.exe ingest.py

To rebuild after any document change, run ingest.py before restarting the
web app. Uploaded PDFs are handled by the application and indexed immediately
when supported.

In the sidebar, Remove Papers can remove selected documents and their indexed
chunks. The app asks whether to move the PDF to removed_pdfs\ or delete it.

- Keep a backup copy in removed_pdfs\ if the PDF may be needed again.
- Move a PDF from removed_pdfs\ back into data\ and re-run ingest.py to add
  it again.


COMMAND-LINE OPTIONS
--------------------
Search the local vector index without using the app:

   .\venv\Scripts\python.exe query.py

Run the fixed RAG example using the default question:

   .\venv\Scripts\python.exe rag.py

Both commands require chroma_db to have been created by ingest.py. rag.py also
requires GROQ_API_KEY in .env.


TEST THE PROJECT
----------------
Run automated tests with the virtual environment:

   .\venv\Scripts\python.exe -m pytest

The test files cover PDF upload, library management, quizzes, and comparison.
Install pytest separately only if your Python environment reports that pytest
is missing:

   .\venv\Scripts\python.exe -m pip install pytest


OPTIONAL EVALUATION
-------------------
Run retrieval-only evaluation, which does not call Groq:

   .\venv\Scripts\python.exe evaluator.py --retrieval-only

Run the full retrieval and LLM-judging evaluation:

   .\venv\Scripts\python.exe evaluator.py

Resume remaining Groq judging runs from saved results:

   .\venv\Scripts\python.exe run_judging.py

These operations may take significant time and can consume Groq API usage.
They update evaluation JSON files and choose chunking settings used by future
ingestion.


COMMON PROBLEMS
---------------
1. "python is not recognized"
   Install Python 3.11 and enable Add Python to PATH, reopen the terminal, and
   run python --version again.

2. PowerShell cannot activate the virtual environment
   Run:

   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   .\venv\Scripts\Activate.ps1

   Or use activate.bat from Command Prompt.

3. "No module named streamlit" or another package is missing
   Activate venv, then run:

   python -m pip install -r requirements.txt

4. Groq authentication or API-key error
   Check that .env is in the project root, contains GROQ_API_KEY exactly once,
   and contains a valid key. Restart Streamlit after changing .env.

5. Streamlit cannot find app.py
   Confirm that the terminal is in the project folder containing app.py.
   Run dir or Get-ChildItem to list the files.

6. The first run downloads slowly
   The embedding model is downloaded on first use. Keep internet access active
   and wait for the download to finish; later runs use the local cache.

7. Ingestion reports that no PDFs were found
   Place PDF files directly in data\, then run ingest.py again.

8. Answers are missing or refer to stale documents
   Add or remove PDFs, then rebuild chroma_db:

   .\venv\Scripts\python.exe ingest.py

9. Port 8501 is already in use
   Stop the existing Streamlit terminal, or start on another port:

   python -m streamlit run app.py --server.port 8502

10. Streamlit says the port is in use and displays another port
    Open the Local URL printed in the terminal; it is authoritative.
